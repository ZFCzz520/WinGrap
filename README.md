# WinGrab 1.0.1

当前发布目录已改为托管依赖单文件整合：主目录为 `WinGrab.exe`、5 个 WPF 原生 DLL、使用说明及校验清单；FFmpeg 和许可证放在子目录。无需安装 .NET。没有启用程序集裁剪、运行时压缩或原生库自解压，不会为减少文件数量而牺牲 WPF 兼容性或每次启动先解压整个应用。请保留这 5 个 DLL。

界面已更新为纸白 / 墨色 / 酸黄的工业风格：切角操作按钮、编号队列、本地宽体字体，以及与主界面融合的窗口控制区。原生灰色标题栏已移除；窗口仍支持拖动、双击标题区最大化 / 还原、边缘缩放及系统贴靠。右上角按钮可最小化、最大化 / 还原和关闭。

按照《短视频下载器-总体设计文档》实现的 Windows 桌面下载应用，当前为 **1.0 内部验收版**。

## 运行

分享安装版时发送 `artifacts/WinGrab-Setup-1.0.1.exe` 即可，详见 `artifacts/WinGrab-安装说明.txt`。安装器包含离线应用、运行环境与 FFmpeg，采用独立的终末地风格安装/卸载界面和实际进度条。默认按当前用户安装，可修改路径并选择桌面快捷方式；开始菜单和 Windows“已安装的应用”均提供卸载入口。卸载先确认，保留下载与个人设置。安装包目前未代码签名。

双击现有 `artifacts/WinGrab-1.0.1-win-x64/WinGrab.exe`。后续更新直接覆盖这个目录，旧 ZIP 不同步更新；不要从旧压缩包启动或覆盖新版。请保留整个目录及其子目录，不要只取出 EXE。便携程序包含 .NET 自包含运行时与 FFmpeg，无需安装开发环境。

1.0.1 修复了旧版手工打包导致的 CoreCLR 依赖清单缺失；历史记录改为首屏绘制后后台加载；重复启动会唤回已有窗口；新增 EXE、窗口及任务栏使用的多尺寸下载图标。启动状态记录位于数据目录的 `startup.json`，不包含 Cookie 或链接。

当前已在本机 Windows x64 验证。Windows 10 1809+ / Windows 11 为设计目标，其他系统版本和 ARM64 尚未实机验收。

首次启动确认使用须知，然后粘贴链接或分享文字，点击“解析链接”，选择清晰度与格式，点击“加入下载”。多条链接每行一条，逐条预览确认后入队；单批最多 30 行。

输入区上方可切换“哔哩哔哩”和“抖音（实验性）”。两个平台分别保留未提交的输入内容；粘贴支持的链接时会自动识别平台。切换不会影响已经加入队列的下载。

B站分P及视频附带的公开合集会显示“选集下载”。默认选中链接当前集，可勾选多集、全选、取消全选，点击“下载所选”或“全部下载”。选择的 MP4 / 音频 / 封面格式适用于整批任务。每集单独入队、按并发获取地址，可暂停及恢复；同格式与画质的已有活动任务会跳过。逐集严格检查画质，缺少所选画质时提示失败，不会自动降级。切换链接点击“更换链接”。合集页、收藏夹、主页等列表链接请改用其中一个视频链接。

确认框、错误信息、关于、扫码登录、目录 / FFmpeg 选择，以及任务与托盘菜单，统一采用终末地风格。路径选择器支持输入路径、驱动器切换和上级导航；无效路径以窗口内提示显示。

## B站扫码登录与 1080P

本次已直接更新现有 `artifacts/WinGrab-1.0.1-win-x64` 目录，旧 ZIP 未同步更新，请从该目录打开 EXE。

点击左侧“扫码登录 B站”，使用手机 B站 App 扫描二维码，并在手机上确认登录。窗口显示“登录成功”后关闭，应用会重新解析当前链接，优先选择来源实际返回的普通 1080P / H.264。登录入口也位于偏好设置中。

扫码会话约 3 分钟有效；过期可刷新，关闭窗口会停止轮询。再次打开登录窗口可检查账号或“退出本机登录”。凭证经 B站账号接口验证后才以 DPAPI 加密保存，不保存密码、不上传产品服务器、不读取浏览器凭证。退出本机登录会删除本机凭证，不表示远程注销 B站的所有会话。

扫码不会提升账号权限：视频没有 1080P、登录已失效或平台限制访问时，仍以实际可用档位为准。浏览器 / 手机登录不会自动同步到本应用。登录前后的解析缓存已隔离，用户不需要等待旧缓存过期或重启应用。

## 已实现

偏好设置现为主窗口内的独立页面，与下载工作台、下载历史采用同一导航。侧栏只高亮当前页面；保存设置在页内显示结果，后台下载更新不会改变当前页面。扫码登录和目录 / 文件选择仍使用各自的操作窗口。

偏好设置修改后，页头会显示红色保存提示。离开设置页、关闭窗口或退出应用时，可选择“保存并离开”“不保存”或“继续编辑”；保存失败会留在设置页并保留输入。扫码登录成功后，窗口顶部显示账号信息，中央显示绿色对勾。

本次就地更新增加：清晰度按视频源实际声明展示，受限项标注登录 / 会员需求，选择时打开扫码窗口；取消登录不会下载，授权后保留选择并重新检查权限。默认每档优先 H.264，不为不存在的档位编造媒体地址，也不会在重试时把所选高清静默换成低画质。

下载类型可选“视频 MP4（含声音）”“仅音频 M4A”“仅音频 MP3”“仅视频封面”；封面保留原始图片字节并按实际格式保存。加入一个下载后可以继续选择其他类型，无需反复解析。任务卡片显示输出类型。

历史页的每条记录可通过“⋯ → 删除此历史记录（保留文件）”删除；“清空历史”批量删除已完成、失败或已取消的记录。两种操作都会确认，均保留已下载文件；运行中、排队和暂停任务不会删除。删除会同步 SQLite，重启后不会重新出现。

- B站普通 BV / av 视频、b23 短链、分P、DASH 与单段 durl；动态图集与动态内嵌视频适配。
- 抖音视频 / 图文 / 短链适配，从官方移动分享页读取公开 JSON；对平台下发的匿名访问会话仅在本次解析中临时使用，不读取浏览器账号。保留平台返回的播放地址，页面访问受限时明确提示，仍标为实验性。
- 标题、作者、封面、时长与实际返回的清晰度 / 编码预览。
- MP4、M4A、MP3；图集按顺序下载为 ZIP；FFmpeg 本机处理音视频。
- 分片下载、暂停 / 继续 / 取消、有限重试、过期直链重新解析一次、进度与速度。
- 全局限速；默认 2 个任务并发，可设 1–4；命名模板、文件冲突追加序号。
- SQLite WAL 任务记录；重启后的未完成任务保持暂停，可手动继续；最近 90 天历史与重新下载。
- 剪贴板事件监听、文本拖入、启动链接参数、单实例检查。
- 关闭主窗口后保留托盘图标并继续下载。双击托盘图标打开主界面；右键可添加链接、查看下载历史、打开设置或退出。退出时暂停并保存未完成任务，下次打开后可继续；隐藏时再次启动程序会恢复原窗口。
- 按平台导入 Cookie，Windows DPAPI 本机加密，支持清除；不从浏览器自动提取凭证。
- 错误码、重试、复制诊断信息、打开日志目录；解析器契约与独立程序集发现。
- 可选 HTTPS 平台开关配置与本地缓存。默认未配置外部服务，不上传遥测。

## 续传规则

服务器支持 HTTP Range 且返回强 ETag 或 Last-Modified 时，分片可安全续传。资源长度或验证标识改变会重新下载。服务器不提供验证标识 / Range 时使用单请求，重试从头开始，避免静默拼接不同版本文件。

## 设置及数据

- 下载默认保存到 `%USERPROFILE%\Downloads\WinGrab`，可在“偏好设置”修改。
- 设置、SQLite、临时分片与日志在 `%LOCALAPPDATA%\WinGrab`。
- Cookie 分别存入 `bilibili.credentials.dat` 与 `douyin.credentials.dat`，只对当前 Windows 用户可解密。
- B站高清按来源接口权限返回，不保证任意最高画质。仅提供常规非会员专享档位。
- 日志不记录 Cookie、媒体 URL 或作品标题；诊断只复制任务 ID、状态与错误码。
- 代理更改后重启生效。可用 `WINGRAB_DATA` 环境变量指定隔离的数据目录。

## 当前限制

平台真实下载成功率尚未以授权样本集验收，不能把离线样本通过视为平台全站可用。平台改版、网络风控及 Cookie 失效均可能导致失败，抖音尤其如此。

当前不支持番剧 / 会员专享 / 付费 / 私密 / DRM / 直播 / 主页采集、签名逆向、去水印。部分动态图文接口可能要求登录或平台签名，失败时不绕过限制。多段 durl 暂不处理。

本版暂未包含托盘通知、历史搜索、任务重排、独立 CLI、诊断 ZIP、自动更新、插件签名与隔离热更和代码签名。作者及发布者元数据为 superman；该署名不代表已经过证书验证。插件只应放入可信的本地程序集。未进行性能指标、8 小时稳定性、干净机器及 ARM64 验收。公开发布前应补齐验收、依赖安全复核和许可证分发资料。

## 开发与验证

使用 Windows .NET 8 SDK，运行：

```powershell
./build/Build.ps1
# 已准备组件后精简发布并就地更新现有目录（不生成 ZIP）
./build/Build.ps1 -Package
```

解决方案分为 Contracts（插件契约）、Core（模型与规则）、Parsers（平台映射）、Infrastructure（下载与存储）、App（WPF）。二维码使用本地引用的 QRCoder 1.8.0（MIT），DLL 与许可证位于 `src/WinGrab.App/lib`；只调用 PNG 渲染器。离线可执行测试位于 `tests/WinGrab.Tests`，通过模拟 HTTP 响应验证解析与实际字节完整性，存储测试使用真实 SQLite 和 DPAPI。

详见 `docs/TEST-REPORT.md`、`docs/THIRD-PARTY.md`。
